# Чекер

Проверка ПК игрока для GTA V
**Скачать:** [Checker.exe](https://github.com/nemo5rp/checker/releases/latest/download/Checker.exe)

- Только чтение: система не меняется, в сеть ничего не уходит!
- Отчёт (HTML + TXT + SHA-256) сохраняется рядом с файлом, игрок передает его сам.
- Пароли, токены, переписку и историю браузера программа не читает!

Если Windows показывает «Защитник Windows предотвратил запуск неизвестного приложения»: файл не подписан, нажмите «Подробнее» → «Выполнить в любом случае».
